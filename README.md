# Paulopelicer.github.io

Portfólio profissional de **Paulo Cesar Hermano Pelicer**.

## Publicação

1. Crie um repositório chamado exatamente `Paulopelicer.github.io`.
2. Envie todo o conteúdo desta pasta para a branch `main`.
3. Vá em `Settings > Pages`.
4. Em **Build and deployment**, selecione `Deploy from a branch`.
5. Branch: `main` / pasta: `/ (root)`.
6. Salve.

Seu site ficará em:

`https://Paulopelicer.github.io`
